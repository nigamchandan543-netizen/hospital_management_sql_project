
🏥 Hospital Management System

📌 Project Overview

The Hospital Management System is a database project developed using MySQL. The project manages important hospital information such as:

Patients

Doctors

Departments

Doctor-Department relationships

Appointments

Medical Records

Billing and Payments


This project demonstrates important SQL concepts, including CRUD operations, joins, subqueries, aggregate functions, window functions, date functions, string functions, and CASE statements.
